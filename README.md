# Jogo de Damas em Java

Projeto feito em Java no Eclipse, rodando no terminal.

## Como rodar no Eclipse
1. Abra o Eclipse.
2. Va em File > Import > Existing Projects into Workspace.
3. Selecione a pasta do projeto e clique em Finish.
4. Execute Main.java.

## Comandos
- `5 0 4 1` -> move da linha 5, coluna 0 para linha 4, coluna 1
- `salvar jogo.dat` -> salva a partida
- `carregar jogo.dat` -> carrega a partida
- `sair` -> encerra
